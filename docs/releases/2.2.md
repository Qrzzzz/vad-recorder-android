# 梦话录音机 2.2

- 修复录音写入或保存失败时仍显示正常监听的问题：现在会停止采集并显示错误。
- 修复首次使用被误判为永久拒绝麦克风权限的问题，普通拒绝后可重新申请。
- 修复同秒片段可能覆盖旧录音的问题，为片段增加唯一标识，并禁止覆盖已有文件。
- 修复读取录音列表时改写原始结束时间的问题。
- 修复 Lint 权限与 API 27 主题属性错误，继续支持 Android 8.0（API 26）及以上。
- 更换简约月牙与声波图标，增加 GitHub Actions 构建与发布流程。

下载 `VADRecorder-v2.2.apk` 安装，可使用 `SHA256SUMS.txt` 核对文件。2.2 使用 Release 构建，沿用 2.1 的历史签名以支持覆盖升级，无需卸载旧版或清除录音。

此版本仍使用轻量规则 VAD；短时设备验证不代表整夜人声识别准确率或所有 ROM 的熄屏省电稳定性保证。
