# 梦话录音机 2.4.1

本版处理 #12、#13、#16、#21，集中修复启停、状态更新、自动停止计时和回放互斥。

- 启动未完成时停止，稍后执行的启动不会重新打开麦克风。连续启停按顺序完成旧会话清理，旧回调不能修改新会话状态。
- 保存计数、错误状态和自动停止显示的并发更新不再互相覆盖。
- 监听时长使用单调时钟；系统校时和切换语言不改变时长。修改自动停止小时数仍从本次监听起点计算。
- 开始监听前暂停回放；即使录音仍在加载，稍后返回的播放器回调也不会自动播放。监听期间播放按钮显示“停止监听后回听”，停止后可手动继续播放。

版本为 `2.4.1` / versionCode `11`，保持 minSdk 26、targetSdk 35。未改变录音文件结构、列表布局、恢复机制、VAD 或 30 秒静音收尾规则。

本地验证及真机验收边界见 [2.4.1 验证记录](../internal/v2.4.1-validation.md)。
