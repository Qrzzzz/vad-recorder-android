# 梦话录音机 2.4

2.4 新增单段录音导出与分享，方便在回听后保存或分享重要片段。

- 在录音列表点击“更多”→“分享录音”，通过 Android 系统分享面板选择接收应用。
- 选择“更多”→“另存为文件”，通过系统文件选择器指定位置和文件名，保存完整 WAV。
- 删除操作移到“更多”菜单，保留二次确认；播放、暂停续播和进度拖动保持原有用法。
- 准备文件时显示进度提示并阻止重复操作，完成或失败后提供中英文反馈；取消或失败不改变原录音。

仅支持已完成的单段 WAV。分享只提供临时副本的读取权限，不包含原录音目录或 JSON 元数据；超过 24 小时的副本在下次启动或分享时清理，系统也可能提前回收缓存。需要长期保留时使用“另存为文件”。打开分享面板不代表接收应用已完成接收。

未增加存储或网络权限，未改变录音采集、VAD 与 30 秒静音收尾规则。继续支持 Android 8.0 及以上系统（minSdk 26，targetSdk 35）。版本为 `2.4` / versionCode `10`，使用与既有版本兼容的签名覆盖升级，升级前无需卸载应用。
