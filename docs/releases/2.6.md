# 2.6：批量整理与收藏保护

- **批量整理**：逐条勾选、全选或选择整晚；选择状态保留到界面重建后，刷新仅保留仍存在的已选片段。删除前确认，显示逐项结果，失败与元数据清理未完成可重试。
- **按晚导出**：每晚标题直接导出 ZIP，也支持导出所选片段。沿用本地时间中午到次日中午的分组规则，录音归属依据保存时间。每段保持原始 WAV；编号子目录避免不同来源的同名文件覆盖，不导出内部元数据。
- **收藏防误删**：在片段“更多”菜单收藏或取消收藏。收藏原子持久化；单条删除禁用，批量删除在执行时重新检查并保留收藏，不依赖界面快照。取消收藏后才可删除。
- **空间概览**：显示当前可访问录音目录的 WAV 总量、收藏占用、可清理容量、每晚大小及所选容量；不包括元数据、未完成片段和分享缓存。

ZIP 导出需所有所选片段完整可读，不静默漏掉损坏录音。取消导出不修改原件；失败时清理未完成目标，目标无法清理时明确提示。导出请求在系统文件选择器打开期间可跨界面重建保留。

版本 `2.6`，versionCode `15`，沿用现有应用 ID 与发布签名。保留已有录音与历史元数据，无批量迁移。

验证范围见 [2.6 验证记录](../internal/v2.6-validation.md)。本轮按用户要求不做真机验证，也不重新下载发布附件；远端以 CI、签名/包名/版本校验及 Release API 为发布依据。
