# 梦话录音机 2.3

发布日期：2026-09-12。

本次更新改善已保存录音的回听体验：

- 支持暂停和继续播放，无需每次从头开始。
- 播放选中片段时展开进度条，显示已播放时间和总时长；播放或暂停时都可拖动定位。
- 播放结束后保留进度与时长，可点击“重新播放”。
- 切换片段时结束上一段播放；删除选中片段时释放播放器。
- 切换到设置或应用进入后台时暂停回听。返回原界面后可手动继续；界面重建或退出后需要重新选择片段。
- 支持中英文和深浅色外观，进度条提供无障碍描述。

已有 WAV 录音仍可直接播放。此次更新不改变录音检测、30 秒收尾保存和文件格式。

下载 `VADRecorder-v2.3.apk` 安装，使用 `SHA256SUMS.txt` 核对文件。覆盖升级须使用与已安装版本一致的签名，无需卸载或清除旧录音。
