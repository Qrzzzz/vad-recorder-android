## 初次真机阻断（后续已解除）

ADB 可连接型号 `2210132C`，Android 16 / API 36。安装独立验收包时返回：

```text
INSTALL_FAILED_USER_RESTRICTED: Install canceled by user
```

因此本次尚未完成真实权限弹窗、麦克风采集、后台 30 秒保存或截图验收。手机上正式包仍为 2.1 / versionCode 7，其录音和设置未清除。需要允许手机 USB 安装后继续，不能将“测试包编译成功”当作“真机通过”。

独立验收包与仪器测试已准备好，测试将使用实际权限弹窗、真实文件描述符故障注入，以及扬声器测试音经过真实麦克风/VAD/服务/WAV 的短时链路。测试音不等同于人声准确率或整夜省电稳定性验收。
