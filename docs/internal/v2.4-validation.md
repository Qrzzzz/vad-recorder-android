## 测试环境修正与边界

- Compose 测试时钟需要在异步复制完成后继续推进，才能触发系统分享面板；使用同步等待处理，未改产品实现。
- DocumentsUI 有多个同名 Downloads 文本，最终脚本明确选择导航抽屉中的根目录，并重新查询异步刷新导致失效的节点；导出完成以目标文件哈希确认。
- 独立测试 APK 不包含应用的 Kotlin 运行库；接收 Activity 改用仅依赖 Android 平台的 Java 实现后完成真实跨 UID 验证。
- 早期失败运行不计入最终通过结果。中断的早期测试留下的 UUID 夹具和下载副本在验收后单独清理。
- 尚未覆盖所有第三方接收应用／云文档提供方、实际进程被杀后的写入恢复或整夜录音。复制期间进程被系统终止可能留下不完整目标文件；原录音不受影响。打开分享面板不等于对方已收到录音，`isExported` 不因此更新。
