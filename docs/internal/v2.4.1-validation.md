# 2.4.1 本地验证记录

日期：2026-09-17。范围：#12、#13、#16、#21。版本 `2.4.1` / versionCode `11`。

## 实现约束

- 服务命令和会话字段在 Main 上串行处理；停止同步标记当前引擎关闭，取消待执行启动并等待工作任务退出。停止期间的 START 在清理后执行，后续 STOP 可以取消该重启请求。
- 引擎关闭状态不可逆，停止原因采用首次请求；stop 只终止读取，release 由工作任务 finally 执行。初始化失败也走资源清理。旧服务清理完成前，新服务不获取采集资源或清理临时文件。
- 引擎 UI 回调在主线程执行时核对来源会话；StateFlow 使用 update，变换函数不包含通知等副作用。
- 会话时长基于 elapsedRealtime；墙上时间只用于预计停止时刻。设置与语言刷新保留会话起点。自动停止任务每次唤醒重新核对 elapsed 截止时间，设备睡眠恢复后最多等待约 1 秒的可运行时间再检查，不新增唤醒锁或后台保活组件。
- 主按钮和权限成功回调复用开始入口；入口与服务均在采集前阻止回放，播放器自身也检查互斥状态。停止监听不自动恢复外放。

## 确定性验收

- CaptureLifecycleTest：启动屏障前停止并保留首次停止原因；20 次会话读取/停止/释放；初始化失败释放；两个状态字段的受控并发交错。
- RecordForegroundServiceTest：启动中重复停止及 START→STOP→START；末次 STOP 取消排队重启；旧回调隔离；服务重建等待旧工作任务；启动错误保留；墙上时间前跳/回拨、语言刷新、停用/修改时限仍使用同一起点；睡眠后重新核对截止时间。
- PlaybackControllerTest、RecorderActionsTest：回放在发出服务启动请求前暂停；加载中的自动播放意图被清除；监听时拒绝回放；监听结束后保留手动续播。
