# 梦话录音机 2.4.3

本版优化采集 I/O 和历史列表，处理 #17、#18、#19。

- PCM 按帧转换为小端字节并批量写入，复用缓冲；不改变音频内容、VAD 判定、预录或片段保存规则。
- 历史文件扫描和删除在后台执行，显示加载及失败状态。连续刷新以最新请求为准，删除后的旧扫描不会把片段重新放回列表；刷新失败保留已有录音列表，可再次刷新。
- 历史列表保留日期标题与摘要，每段录音独立懒加载。播放及菜单以原始文件路径绑定，插入、删除后不会错位。
- 保持旧 WAV/JSON、内部及外部录音目录、回听、分享与另存为兼容。不迁移历史录音。

验证包含 PCM 字节一致性和写入次数、后台 I/O、请求交错、同一晚 500 段和多晚分组。设备侧结果来自 Android 11 / API 30 模拟器；本轮未连接真机，不作耗电比例或全机型帧率承诺。详见 [验证记录](../internal/v2.4.3-validation.md)。

附件为 `VADRecorder-v2.4.3.apk` 和 `SHA256SUMS.txt`，versionCode 为 `13`。沿用现有签名，可覆盖升级。
